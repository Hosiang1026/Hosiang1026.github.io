2.2 构建速度优化

Maven构建优化

并行构建

mvn clean install -T 4

跳过测试

mvn clean install -DskipTests

离线模式（使用本地仓库）

mvn clean install -o

并行构建

./gradlew build –parallel

使用构建缓存

./gradlew build –build-cache

守护进程模式（默认启用）

./gradlew build –daemon

查看构建时间

./gradlew build –profile
