### 一、破解超管账号密码

#### 1.1 访问光猫管理界面

```
**步骤说明：**
```

1. **打开浏览器，访问光猫默认管理地址**
   - 默认地址：`http://192.168.1.1`
   - **重要提示：** 需要在地址后添加端口号`8080`
   - 完整访问地址：`http://192.168.1.1:8080`

2. **使用普通账户登录**
   - 账号：`useradmin`（光猫背面标签上有标注）
   - 密码：光猫背面标签上标注的密码
   - 使用普通账户登录管理界面

3. **获取设备基础信息**
   - 登录成功后，在浏览器地址栏输入以下地址：
   - 地址：`http://192.168.1.1:8080/cgi-bin/baseinfoSet.cgi`
   - 该地址会返回设备的JSON格式基础信息

![Popular](https://hosiang1026.github.io/photos/image/2024/12/15/h2kbds.png "电信烽火光猫HG6201T破解超管账号密码-路由器篇")

#### 1.2 查找加密的超级管理员密码

在返回的JSON数据中，找到以下字段：

```xml
"baseinfoSet_TELECOMACCOUNT":"telecomadmin", 
"baseinfoSet_TELECOMPASSWORD":"120&105&112&105&103&115&113&101&104&113&109&114&50&52&57&50&53&51&48&55&",

```

```
**字段说明：**
```
- `baseinfoSet_TELECOMACCOUNT`：超级管理员账号，通常为`telecomadmin`
- `baseinfoSet_TELECOMPASSWORD`：经过ASCII编码加密的超级管理员密码

#### 1.3 密码加密原理分析

通过对比光猫背面明文标注的普通账号密码，可以分析出加密规律：

```
**加密方式：**
```
- 将每个字符的ASCII码值加上偏移量4
- 用`&`符号连接所有数字
- 例如：字符`t`的ASCII码是116，加上4后是120，所以加密后为`120&`

```
**解密规则：**
```
- 超级管理员密码格式通常为：`telecomadmin` + 8位数字
- `telecomadmin`部分：每个ASCII码需要减去偏移量4
- 后面的8位数字：偏移量为0（即直接转换，不需要减去4）

#### 1.4 密码解密方法

```
**方法一：对照密码表手动解密**
```

ASCII码数字对照表：
- `&48` → 字符`0`（减去4后为44，对应字符`,`，但数字部分偏移为0）
- `&49` → 字符`1`
- `&50` → 字符`2`
- `&51` → 字符`3`
- `&52` → 字符`4`
- `&53` → 字符`5`
- `&54` → 字符`6`
- `&55` → 字符`7`
- `&56` → 字符`8`
- `&57` → 字符`9`

```
**方法二：使用Java代码自动解密（推荐）**
```

运行以下Java代码可以自动完成解密过程：

```java
import java.util.HashMap;
import java.util.Map;

public static void main(String[] args) {
        Map<String, String> map = new HashMap<>();
        //  获取信息的方式 http://192.168.1.1:8080/cgi-bin/baseinfoSet.cgi
        // fixme,下面两行把从路由器拿到的信息放在这里
        map.put("telecomadmin", "120&105&112&105&103&115&113&101&104&113&109&114&50&52&57&50&53&51&48&55&");
        map.put("useradmin", "107&114&103&110&109&");
        for (Map.Entry<String, String> entry : map.entrySet()) {
            StringBuilder stringBuilder = new StringBuilder();
            String[] split = entry.getValue().split("&");
            for (String s : split) {
                int offset = 4;
                if (stringBuilder.toString().startsWith("telecomadmin")) {
                    offset = 0;
                }
                stringBuilder.append((char) (Integer.parseInt(s) - offset));
            }
            map.put(entry.getKey(), stringBuilder.toString());
            System.out.println(entry.getKey() + " : " + entry.getValue());
        }
```

### 二、IPTV内网融合单线复用

通过VLAN技术实现单线复用，可以在同一根网线上同时传输上网业务和IPTV业务，无需额外布线，简化家庭网络结构。

![Popular](https://hosiang1026.github.io/photos/image/2024/12/15/h2kscn.png "电信烽火光猫HG6201T破解超管账号密码-路由器篇")

#### 2.1 设置光猫VLAN绑定

```
**操作步骤：**
```

1. **使用超级管理员登录光猫**
   - 使用前面获取的`telecomadmin`账号和密码登录光猫管理界面

2. **进入VLAN绑定设置**
   - 点击"网络" → "VLAN绑定"菜单
   - 在"用户侧端口"中，勾选需要开启VLAN绑定的端口
   - **建议选择千兆网口**，以获得更好的性能

3. **配置VLAN ID**
   - **上网业务VLAN ID：** 根据本地实际情况填写（示例中为41）
   - **IPTV业务VLAN ID：** 根据本地实际情况填写（示例中为45）
   - **重要提示：** 不同地区的VLAN ID可能不同，请咨询当地运营商或查看光猫原有配置

4. **保存配置**
   - 配置完成后，点击"应用"按钮保存设置
   - 等待配置生效

![Popular](https://hosiang1026.github.io/photos/image/2024/12/15/h2kn79.png "电信烽火光猫HG6201T破解超管账号密码-路由器篇")

```
**VLAN ID查询方法：**
```
- 查看光猫原有配置中的VLAN设置
- 咨询当地电信运营商客服
- 查看光猫的配置文件（需要技术能力）

#### 2.2 配置路由器IPTV功能

```
**以华为AX3 PRO为例进行演示：**
```

```
**物理连接：**
```
- 将光猫的网线连接到路由器的LAN1口（或其他指定端口）

```
**路由器配置步骤：**
```

1. **登录路由器管理界面**
   - 在浏览器中访问路由器管理地址（通常是`192.168.3.1`或`192.168.1.1`）
   - 使用管理员账号登录

2. **开启IPTV功能**
   - 进入"更多功能" → "网络设置" → "IPTV设置"
   - 开启"IPTV功能"开关

![Popular](https://hosiang1026.github.io/photos/image/2024/12/15/h2koaj.png "电信烽火光猫HG6201T破解超管账号密码-路由器篇")

3. **配置IPTV参数**
   - **连接模式：** 选择"桥接"模式
   - **LAN接口：** 选择连接机顶盒的LAN端口（如LAN2、LAN3等）
   - **开启VLAN：** 勾选"开启VLAN"选项
   - **VLAN ID：** 输入光猫中配置的IPTV VLAN ID（示例中为45）
   - **802.1p优先级：** 设置数据包的服务质量优先级，范围0-7，可根据需要设置（通常设置为0即可）

   - 配置完成后，点击"保存"按钮

![Popular](https://hosiang1026.github.io/photos/image/2024/12/15/h2kvl1.png "电信烽火光猫HG6201T破解超管账号密码-路由器篇")

```
**配置完成后的效果：**
```
- 机顶盒可以通过路由器正常接收IPTV信号
- 路由器其他端口可以正常提供上网服务
- 实现单线复用，无需额外布线

```
**注意事项：**
```
- 不同品牌的路由器，IPTV设置界面可能略有差异
- 如果配置后IPTV无法正常使用，请检查VLAN ID是否正确
- 建议在配置前备份路由器原有配置，以便出现问题时恢复
